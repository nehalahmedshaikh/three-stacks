Three stacks in series

input → S1 → S2 → S3 → output. Each element enters every stack once, in order. Can the machine emit 1,2,3,…?

Every element performs r1 (input→S1), r2 (S1→S2), r3 (S2→S3), r4 (S3→output) exactly once, so a run is always 4n operations. One stack sorts exactly the permutations avoiding 231; two stacks first fail at length 7 (e.g. 2435761); three stacks sort everything up to length 16; whether all permutations of lengths 17–20 sort remains open.
